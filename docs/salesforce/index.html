Overview

Independent Salesforce workbench and Agentforce Studio: connected orgs, SOQL, Apex, deployments and agent tools. Install with `zcc plugin install salesforce@official`.

Salesforce DX inner loop for ZCC: org identity, SOQL, Apex, LWC, and Agentforce tools with fail-closed mutation confirms.

## What you get

- Org identity and doctor checks for the connected Salesforce org.
- SOQL Explorer, Apex and LWC editors, and Agentforce playground and preview.
- Agent tools that require an explicit confirm before any mutating API call.

## How it works

The plugin talks to Salesforce APIs from this host. Reads can run unattended. Writes wait for your approval in the thread.

## Requirements

Install with `zcc plugin install salesforce@official`, then authenticate the Salesforce CLI / DX org this project uses.

## Independent distribution

Maintained in grebmann1/zcc-plugin-salesforce with its own compiled releases. Salesforce is optional on new Zana installations. Existing installations migrate with their settings, saved data and enablement preserved.
