Overview

Pin browser elements, write precise feedback, and attach captured element context to your Zana thread composer.

Annotate a web page beside a Zana thread. Choose Annotate elements in the browser toolbar, click an element, and save your feedback. Numbered pins attach the element text, selector, styles, and best-effort React component context as compact composer references.

Edit or remove pins before sending. Successful send or queue clears the pins; sent messages retain immutable snapshots. The plugin adds no sidebar item.

Requires Zana desktop with the browser annotation support merged in salesforce/zana PR #622, including experimental_browserToolbarAction and the scoped page bridge. Upgrade older builds before installing. No separate browser automation service, CLI, account, or API key is required.

Installed plugins run as full-trust code in the Zana server process. This plugin inspects the page you annotate and stores captured context locally; that context is shared with your selected agent provider when you send the thread message.

An MIT-licensed port of BB Agent Annotations by Michael Yong, retaining the original overlay, capture implementation, and license notice.
