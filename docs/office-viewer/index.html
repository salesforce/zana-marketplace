Overview

Preview Word, Excel and PowerPoint content beside a Zana thread, then quote a section into your draft.

Read .docx documents, .xlsx workbooks and .pptx presentations beside your conversation. Open a file from the project Explorer or a thread attachment; Office Viewer opens automatically. Choose a sheet or slide, then use “Quote section” to add its text to the current conversation draft.

Open Settings → Office Viewer for supported formats, preview limits and a short usage guide in Zana’s standard grouped Settings rows. No additional configuration, Office installation, account or API key is required.

Requires Zana 2.6.1 or later with the current project-file and thread-list SDK APIs. The v0.1.1 Git release includes compiled runtime files. Upgrade older Zana builds before installing.

This is a read-only text and cell-value preview. Files are limited to 8 MiB. Original layout, images, charts, date/number formatting, formula calculation and editing are unavailable. Workbooks show stored values, or formula text when no cached value exists. Password-protected, macro and legacy binary formats are unsupported.

Installed plugins run as full-trust code in the Zana server process. Office Viewer reads the selected project or attachment file through Zana’s scoped file APIs and parses it locally. It sends no telemetry or document content to an external service. Quoted text enters your conversation draft and is shared with your selected agent provider when you send it.

An independently maintained, MIT-licensed Zana adaptation inspired by VKirill’s Office Viewer for BB. Original attribution and source revision are preserved in the plugin repository.
