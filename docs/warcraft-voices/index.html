Overview

Hear Orc, Human and Murloc voices when an agent needs input or becomes idle. Mix characters per alert and download only the voices you want.

Give your agents Warcraft voices: Orc Peon, Human Peasant, Orc Grunt and Murloc. Choose a different character for Needs you and Becomes idle, or use one character for both. Preview each alert in a Warcraft-inspired interface.

Open Settings → Notifications → Sounds, select Warcraft Voices, download the characters you want and choose a voice for each alert. Enable Becomes idle if wanted, then turn on Play notification sounds. Installing the plugin does not change your active sound provider.

Quiet spacing, rotating clips, volume controls and a 30-minute pause help keep multiple sessions manageable. Input alerts take priority; idle means the agent is at rest, not that its work succeeded.

Automatic alerts and the Settings integration require a Zana desktop build containing salesforce/zana PR #698 and the notificationSoundProvider SDK slot. Older hosts retain downloads and manual previews in the plugin Configure section, with automatic playback off. The Git release includes compiled runtime files; no separate CLI, account, API key or dependency installation is needed. Internet access is needed to download characters.

Installed plugins run as full-trust code in the Zana server process. This plugin downloads requested audio from a pinned PeonPing/og-packs revision on GitHub, checks file signatures and SHA-256 hashes, and stores clips and preferences locally. It runs one selected sound provider across windows.

Plugin source code is MIT licensed. Game audio is not bundled. Upstream PeonPing pack manifests declare CC-BY-NC-4.0; source attribution and applicable audio rights are linked in the plugin and its README.
