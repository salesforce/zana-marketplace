Overview

Voice dictation, on-device Local Whisper, AI writing refinement (5 tones), translation, summarization, technical specs, word diffs, and searchable activity history for Zana — no API key needed.

Voice dictation and AI writing workbench for Zana Command Center. Dictate directly inside thread composers, quick-dictate from Zana’s Home screen, or shape spoken, typed, and pasted drafts inside global and per-project **Draft Studio** workspaces before inserting them for review. Nothing is sent automatically.

## What you get

- **Voice Dictation Everywhere**: Record from an inline composer mic pill (scope-gated for main screen, projects, or both), the Home screen quick-dictate card, or the Draft Studio canvas with live audio metering, microphone selection, sound cues, and a personal spelling dictionary.
- **On-Device Local Whisper**: Install a pinned `whisper.cpp` server runtime and download verified multilingual Whisper models directly from **Draft Studio → Settings** for offline transcription (Windows x64 and Linux x64), or use Zana host voice, OpenAI, or Google Gemini.
- **AI Writing & Transformations**: Improve writing across 5 tones (*Standard, Casual, Conversational, Professional, Technical*), summarize into crisp executive bullet points, structure rough notes into a technical spec (`Goal`, `Architecture`, `Implementation Steps`), translate naturally while preserving code/Markdown, or run custom instructions.
- **Diff Review & Model Selection**: Inspect word-level diffs between input and refined output, switch between dynamically discovered Zana host models (sorted cheapest-first) or direct API keys, and sync automatically with the active composer provider.
- **Activity History & Privacy Controls**: Search, filter, star, and reload past dictations and refinements with configurable entry/day retention limits and one-click history clearing.

## Get started

Install with `zcc marketplace install draft-studio@zana-community`. Defaults use Zana’s built-in host voice transcription and assistant inference, so no external API key is required. Configure surface visibility, microphone, sound cues, Local Whisper, or optional API keys in **Settings → Draft Studio**.

## Requirements & runtime

Requires Zana `>=1.0.0` and microphone access for voice dictation. Managed Local Whisper downloads pinned `whisper.cpp` (`v1.9.5`) binaries and Hugging Face model weights verified by byte size and SHA-256 on Windows x64 and Linux x64 (macOS and arm64 Local Whisper builds are not yet enabled). Choosing OpenAI, Google Gemini, or Anthropic providers sends audio or text to those APIs using your configured API keys.
