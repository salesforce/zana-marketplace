Overview

Connect Orgo Linux computers to Zana with automatic SSH setup, and manage their power state from one panel.

Connect a running Orgo Linux computer to Zana from the sidebar. The plugin prepares a dedicated SSH key, updates its managed SSH configuration, and pairs the machine through Zana. Reconnect refreshes changed endpoints and reuses existing enrollments.

Browse computers across Orgo workspaces, filter the list, inspect SSH details, and start, stop, restart, suspend or resume computers when supported. Destructive power actions ask for confirmation.

Requires Zana desktop on macOS or Linux, an Orgo account with API access, and a running Linux Orgo computer for pairing. Orgo subscription and usage charges apply separately. Configure the API key in the private local credential file described in the repository README.

Installed plugins execute as full-trust code in the Zana server process. This plugin contacts Orgo over HTTPS and writes its dedicated SSH identity and managed configuration locally. It preserves existing SSH keys and does not receive host-daemon tokens.
