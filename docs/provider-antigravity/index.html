Overview

Run Zana threads through Google’s Antigravity Native ACP server, with account controls, native models, planning and subscription usage.

Add Google Antigravity as a Zana thread provider through the Native ACP server, agy_acp_server. Use the native model catalogue, Plan mode, account recovery from the thread side panel, and subscription usage checks in Settings.

## Get started

Install with `zcc marketplace install provider-antigravity@zana-community`. Open Settings → Antigravity Provider, choose your authentication method, and verify the session and models. Start a thread and select Antigravity.

## Requirements

Requires a compatible Zana desktop build (the package declares Zana >=2.2.2), network access, and a Google account or credentials entitled to use the selected authentication method and models. Google subscription or API charges apply separately. Model availability depends on your account. Supported runtime targets are macOS Apple Silicon and Intel, Linux x64 and arm64, and Windows x64.

## Runtime and credentials

The plugin can download a managed Google Native ACP distribution and verifies its archive with SHA-256 before extraction. You can configure a native executable override. It supports personal OAuth, business OAuth, Gemini API key and agent-platform authentication. Credentials and settings are maintained locally; thread content is sent to the selected Google service.
