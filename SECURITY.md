# Security Policy

Please do not report security vulnerabilities in public GitHub issues.

Report a vulnerability in this catalog privately through
[GitHub Security Advisories](https://github.com/salesforce/zana-marketplace/security/advisories/new).
Include a clear description, the affected listing or file, reproduction steps,
and any suggested mitigations. Maintainers will acknowledge valid reports and
coordinate a fix and disclosure.

This repository only lists plugins; it does not host their code. Report a
vulnerability in a plugin itself to that plugin's own repository. For Zana
itself, use the [Zana security policy](https://github.com/salesforce/zana/security/policy).
If you are unsure where a report belongs, send it here and we will route it.
